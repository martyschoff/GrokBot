# GrokBot

App sources for Martin's Grok Bot projects. App trees live under `apps/<app>/`.

The English NT player lives at `apps/nt4me2/` (Bible Vision chrome). Live audio on S3 `nt4me2` stays with Kimberly — this repo is chrome/player only.

See `apps/nt4me2/README.md` for Settings toggles, Galatians 1–2 sew fixtures, Berean/KJV hooks, and how Kimberly wires real fragment mp3s / `live.json` keys.
